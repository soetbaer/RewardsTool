Den täglichen Lauf kannst du jetzt **direkt im Webinterface an- und ausschalten**, zum Beispiel im Urlaub.

## ✨ Neu
- **Schieberegler „Täglicher Lauf“** auf der Startseite und in den Einstellungen: **grün = an**, **rot = aus**.
- Ausgeschaltet heißt: Es startet kein automatischer Lauf mehr. „Lauf starten“ funktioniert weiterhin.
- Gilt für **Windows** (die Aufgabe „RewardsTool“ in der Aufgabenplanung wird deaktiviert) und **Linux** (der
  systemd-Timer wird abgeschaltet).
- Ein erneutes Ausführen von `Setup.bat` oder `install.sh` schaltet einen ausgeschalteten Lauf nicht wieder ein.

## Hinweis für Linux-Server
Damit der Timer ganz abgeschaltet wird, braucht das Hilfsskript die neue Version. Dafür einmal auf dem Server:
```
cd ~/RewardsTool && bash deploy/install.sh 08:00
```
Ohne diesen Schritt funktioniert der Schalter trotzdem: Der Timer läuft dann zwar weiter, seine Läufe werden aber
übersprungen.
