Fehlerbehebung für **„Auf Bing erkunden“**.

## 🐞 Behoben
- **„Cleverer Bankgeschäfte machen“** wurde nicht gutgeschrieben. Es wird jetzt nach „Girokonto Vergleich“ gesucht.
- **„Lernen Sie Liedtexte“** wurde nicht gutgeschrieben. Es wird jetzt nach „Lyrics“ und einem bekannten Songtitel
  gesucht, der Titel wechselt zufällig.

## ✨ Verbessert
- In `config.json` kann ein Thema unter `activities.topic_queries` jetzt auch **mehrere Suchbegriffe** haben
  (als Liste). Pro Lauf wird zufällig einer gewählt.
- Gibt es für ein Thema keinen Suchbegriff, steht im Log „Kein Suchbegriff für Thema …“. So lässt sich der
  passende Eintrag schnell ergänzen.

## Update
Ab 1.1.0 einfach im Webinterface auf **„Jetzt aktualisieren“** klicken. Deine eigenen Einträge in der
`config.json` bleiben erhalten, die neuen Themen kommen dazu.
