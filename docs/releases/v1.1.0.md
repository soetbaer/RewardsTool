## ✨ Neu

### 🔄 Automatische Updates
Das Webinterface sieht alle 6 Stunden auf GitHub nach einer neuen Version. Gibt es eine, erscheint oben ein Hinweis
mit **„Was ist neu?“** und **„Jetzt aktualisieren“**. Nach etwa einer Minute ist die neue Version aktiv, die Seite
lädt sich selbst neu und du bleibst angemeldet.

- **Manuell** (Standard): Du entscheidest, wann installiert wird.
- **Automatisch**: Updates werden installiert, sobald gerade kein Lauf aktiv ist.
- Sicher: Die Prüfsumme des Pakets wird kontrolliert. `profile`, `data` und `logs` werden nie angefasst. Deine
  Werte in der `config.json` bleiben erhalten. Die alte Version wird vorher gesichert und bei einem Fehler
  wiederhergestellt.

## Update von 1.0.0

**Windows**
1. `RewardsTool-1.1.0.zip` unten unter **Assets** herunterladen.
2. In **denselben Ordner** wie bisher entpacken und Dateien überschreiben lassen.
3. **`Setup.bat`** erneut starten. Deine Microsoft-Anmeldung bleibt erhalten.

**Linux-Server:** Am Server anmelden und diese Befehle eintippen. Sie laden die Version direkt von GitHub,
du musst also nichts vorher herunterladen oder kopieren:
```
cd ~
sudo apt-get install -y curl unzip
curl -fLO https://github.com/soetbaer/RewardsTool/releases/download/v1.1.0/RewardsTool-1.1.0.zip
unzip -o RewardsTool-1.1.0.zip && rm RewardsTool-1.1.0.zip
cd RewardsTool && bash deploy/install.sh 08:00
```
Die Uhrzeit am Ende ist die tägliche Startzeit.
`install.sh` richtet dabei zusätzlich die Berechtigung ein, mit der das Webinterface die Uhrzeit des täglichen
Laufs ändern darf. Dafür bekommt der Dienst-Benutzer per sudoers genau ein Hilfsskript freigegeben, sonst nichts.

> [!NOTE]
> Hast du die `config.json` angepasst, sichere sie vor dem Entpacken. Beim Update per Hand wird sie überschrieben.
> Künftige Updates über das Webinterface behalten deine Werte.
